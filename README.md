# ИОС ВУЦ — Информационная образовательная система

Единое цифровое пространство для образовательной деятельности Военного учебного центра Чувашского государственного университета имени И. Н. Ульянова.

---

## О проекте

**ИОС ВУЦ** (Информационная образовательная система) — современная веб-система, предназначенная для комплексной цифровизации учебного процесса, взаимодействия преподавателей и курсантов, сопровождения образовательных программ и электронного документооборота ВУЦ.

Проект разрабатывается с чистого листа на независимой кодовой базе с сохранением преемственности фирменного стиля официального сайта ВУЦ ([вуц21.рф](https://вуц21.рф)).

- **Фреймворк**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) (strict mode)

- **Маршрутизация**: [React Router 6](https://reactrouter.com/)

## Установка и запуск

### Требования

- Node.js 18+ (рекомендуется LTS или 20+)
- npm 9+

### Установка зависимостей

```bash
npm install
```

### Запуск через Docker Compose (Рекомендуется)

```bash
docker compose up -d --build
```

Сервис будет собран в оптимизированном Nginx-контейнере и доступен по адресу: [http://localhost:3000](http://localhost:3000).

Остановка контейнера:
```bash
docker compose down
```

### Локальный запуск без Docker (Dev-режим)

```bash
npm install
npm run dev
```

Локальный dev-сервер будет доступен по адресу: [http://localhost:3000](http://localhost:3000).
